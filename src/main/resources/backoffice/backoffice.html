Подготовка Bitrix24

1. Создайте на портале клиента серверное локальное приложение с интерфейсом. Путь к обработчику: https://offer.abs7.ru/bitrix/mobile. Путь для первоначальной установки: https://offer.abs7.ru/bitrix/install. Выдайте права crm, placement, mobile, user_basic, im и сохраните приложение — desktop-размещения привяжутся автоматически во время установки.

2. Создайте входящий webhook с доступом к CRM и сотрудникам и вставьте его REST URL ниже. Он нужен back-office для проверки подключения, синхронизации сотрудников и независимых серверных проверок доступа.

3. Если это отдельное локальное приложение клиента, после сохранения Bitrix24 покажет Client ID и Client Secret — сохраните их ниже, чтобы сервер мог обновлять OAuth-токены клиента.

Отдельное локальное приложение клиента
Оставьте пустым, если используется основной OAuth/Marketplace app. Нужны только если у клиента собственное локальное приложение и его refresh token должен обновляться нашими серверами.
