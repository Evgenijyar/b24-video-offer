UPDATE 019 — DESKTOP CAMERA RECORDING

1. Desktop Bitrix widget now has a source switcher:
   - "По ссылке" — existing Kontur.Talk workflow, unchanged and selected by default.
   - "Записать видео" — direct camera/microphone recording from the desktop Bitrix widget.

2. Desktop recorder:
   - automatic camera request when recording mode is selected;
   - cycles through available video input devices;
   - one record/stop button (red circle -> red square);
   - live timer;
   - playback of the completed recording;
   - re-recording replaces the temporary recording;
   - H.264/AAC MP4 preferred, WebM fallback;
   - 1.8 Mbps video / 96 kbps audio target;
   - 2-second chunks, up to 4 parallel uploads, retries and timeouts;
   - server-side fast remux/transcode pipeline reused from mobile recording.

3. Offer creation after desktop recording reuses the existing uploaded-video offer path,
   so timeline delivery, public page, retention and view notifications remain identical.

4. Desktop widget response now explicitly sends Permissions-Policy for camera/microphone
   and no-store security headers.

5. Cache-busting version for desktop CSS/JS updated to v=019.

No DB migration. No application.properties changes. No Bitrix reinstallation required.
