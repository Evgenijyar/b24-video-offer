Update 027

Desktop screen-capture window lifecycle / geometry hardening:
- Removed reliance on resizable=no as the sole size constraint.
- Added hard picker-size lock (612x614 outer px) using resize event repair + watchdog.
- Added native resize-lock probes when exposed by host: Additional Windowing Controls, Chrome App window API, Electron remote bridge.
- Added multi-path native minimize after getDisplayMedia resolves: window.minimize, chrome.app.window, chrome.windows, Electron/known host bridges.
- Native minimize is attempted directly before browser fallback.
- Browser fallback no longer shrinks the agent; it repeatedly hands foreground back to the Bitrix host from both the agent and embedded widget to survive Chromium post-picker refocus.
- Screen recording/segment upload/preview pipeline is unchanged.
- Cache-busting advanced to v=027.
